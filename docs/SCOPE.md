# OMP-Desktop 需求与验收边界

## 产品定义

OMP-Desktop 是本机已安装 omp 的桌面前端。沿用现有桌面交互与原生 omp 适配，移除 PI 自己的 Agent 内核及额外业务系统；PI-Desktop-main 与 pi-desktop-master 是只读交互参考，当前视觉以本文件的 Goal 为准。不宣称完整平台、服务商或快捷键矩阵已经验证。两个参考项目和 oh-my-pi 源码保持不变。

## 当前 Goal：PI 启发、OMP 原生的语义呈现

- PI-Desktop 提供对话主线、过程层级和阅读交互原则，不是 OMP 协议、消息类型或功能的上限。保持中性深色基础样式，不新增主题、材质或运行时；OMP 特有与未来可见类型按真实作者、归属、生命周期和交互呈现。
- 人类输入逐字可辨、可选择，HTML/Markdown 定界符不因富文本解析消失；原生标注为用户的 skill/collab 输入保留用户归属及真实 custom 类型。作者、可见性、消息族与是否开启新轮分别判断，代理分配不伪装成本地手输请求，隐藏指令不进入普通对话。
- 输入区回执保留原始意图、目标会话及受理/完成/失败/未知事实，主进程命令 ID 与预期 session ID 防止误投。运行中后续消息由桌面队列持有，不自动进入 native follow_up；收敛后发送下一项，Stop 暂停且不在随后自动发送，用户可明确立即插入、停止并发送、编辑或删除。原生 ACK 仍不等于逐项送达，迟到失败不被受理回执覆盖。
- 每轮按用户消息、过程、答复、后续更新、页脚阅读；运行中仅过程与最新文字尾部，收敛后才分类答复。耗时扣除等待用户，问题按结果计算；失败仅一个错误卡，恢复、预期失败与用户停止不制造问题。提供者片段与后台活动不制造假用户轮次，真实重复及部分正文保留。
- 异步交付先核对授权 roster、原生别名与实际 task 调用。可证实的迟到结果归回原委派，混合批次可有多个所有者；task/bash/eval、图片、schema/捕获错误与残余内容分别保留。无法证明归属时按原顺序标为中性的会话活动，不按邻近位置、点号 ID 或通知措辞猜测。
- 主/子会话共享语义阅读，保留真实多层及多父出现关系、实时/保存身份与来源上下文；子任务分配是元数据，不因分页缺少用户行而补造提问。主代理结束不等于仍被观测的后台任务结束。
- 原生压缩/分支/reset、命令输出、诊断/advisor/IRC/交接、重试恢复、中断及未知可见内容有各自说明；未知内容先显示声明的正文/媒体，再给有界技术预览和已有授权下的完整来源入口。签名、隐藏推理与提供者回放不当作正文。
- 临时回执、实时序列与活动有界，缺页、截断与来源失败可见，不建第二套 journal。手动折叠、焦点/选区/锚点优先；历史窗口 Latest 读真实最新页，流式最新返回开始即恢复跟随，两屏内 300ms 追向实时底部，更远或减少动态效果时立即跳转，不重复读取历史，程序滚动不当作用户操作。
- 本轮改动默认是一份最终净文件清单与逐文件 diff，不累计中间操作；过程/来源按需展开。无需 Git，始终结合有界 RAM 哈希/内容与已授权主/子工具证据；改回原样仅在证据可证明时省略，哈希确认的变化不因正文或作者未知而隐藏。当前 Git 工作区另列，不以 HEAD 删除行数冒充本轮基线。
- 捕获只覆盖已声明的有界工作区扫描范围，动态内存压力下先释放正文、保留哈希；没有应用磁盘快照/溢写或永久中间版本，不承诺全项目覆盖、操作系统零 swap 或未经测量的大于 5GB 工作区性能。重启/淘汰后与外部旧轮次从完整原始历史分段收集工具证据、增量归约净结果，不以累计历史长度停止；正文载荷仅在 RAM 中处理，保留既有可丢弃的偏移/身份元数据索引。过程明细的 256 步 / 1 MiB 展示预算不限制最终证据处理。不补造历史终点，区间变化不证明独占作者，单个 patch/diff 仍有运算边界；具体说明见架构。
- 前一阶段的会话移除、空会话/持久来源区分、保守写入准入和输入焦点继续保留；引擎、认证、执行权限与来源/资源授权边界不变。
- 当前滚动与输入修正覆盖逐提交文字锚点、明确用户输入、导航取消与请求生命周期、子行实测高度、FLIP 基线、同文件刷新保留及历史树同源原子刷新；运行时最新权威独立于视口锚点。文本输入只保留一层表面及可见键盘焦点，不重置非文本原生控件。主/子阅读、审阅/文件刷新、多类输入及最终包历史搜索的已观察范围见 [滚动与输入验收](VERIFICATION.md#当前验收滚动抖动与输入内层黑框修正--2026-10-01)；未实测的原生 select/扩展 prompt、子分页与文本选区不由其他成功外推。下方旧包文件清单证据仍仅证明当时范围。
- 集成检查、真实原生与 Electron 场景及最终证据由编排者负责；当前 [原会话缺文件回归验收](VERIFICATION.md#当前验收原会话最终答复缺文件回归--2026-10-01) 已记录只读冻结父/子历史的固定轮次在新进程模块 smoke 中恢复 15 个文件、完整且不再 pending，以及 35 项定向行为测试、两个 TypeScript 配置及生产构建通过。重建后 Electron 与当前未签名 mac-arm64 包均实际显示该轮 15 文件、已知精确小计 +35/−7 及 `contracts.ts` 的原生精确 diff，无收集中、部分覆盖提示或警报；文件身份与最终文档端点不等于全部 patch/行数精确，也不外推所有历史来源。此前 [分段回归](VERIFICATION.md#历史验收历史最终改动分段回归修正--2026-10-01) 的一文件原生编辑、无改动答复、冷启动及旧包 diff 仅证明各自场景；长正文 fixture 的界面无响应也不是当前原会话空白原因的证明。此前最终改动及 [整体体验](VERIFICATION.md#当前验收整体体验升级--2026-09-30) 各阶段仅证明各自已观察范围，不从旧包、模块或历史证据外推当前实际界面。

## 必须保留

- 原有桌面布局、项目/会话侧边栏、可调整工作面板、字体、菜单、弹窗与基础状态呈现；主题选择按当前 Goal 移除。
- 富文本、代码、思考折叠、工具调用/结果、subagent 过程与详情、会话恢复、真实运行/停止/失败状态。
- 输入草稿、模型/思考级别选择、附件、文件引用、发送/停止与运行中消息交互。
- 文件浏览/预览、差异展示、会话搜索以及必要桌面快捷操作。
- omp 要求用户回答或批准的交互，不得静默批准、忽略或以成功占位。

## 必须移除

- PI Agent runtime、Rust host、PI 工具/subagent/search/重试/记忆的独立实现。
- PI 插件市场、计划任务、PR 工作流、远程主机、云同步及额外提示词增强调用；对应入口一并移除。
- PI 产品名、更新地址、默认模型和配置语义；版权与许可声明必须保留。

## omp 与桌面各自所有权

- omp：模型请求、工具、MCP、Skills、扩展、subagent、搜索、认证、会话格式与 Agent 配置。
- 桌面：窗口、布局、基础样式、桌面快捷键、必要的本地文件展示，以及受限 IPC/子进程生命周期。
- 默认调用本机 omp，不捆绑内核，不要求远程服务，不建立第二套 Agent 配置、认证或会话权威存储；临时只读元数据索引不是原生会话副本。
- 自动加入用户配置目录的文件仅为可选只读在场扩展 `<agentDir>/extensions/omp-desktop-presence.ts`，由默认开启的桌面设置控制，可关闭移除，仅更新带管理标记的文件；不修改 omp 本体或另建 Agent 配置/凭据体系。桌面运行时另以 `-e` 加载随包扩展，草稿 autoResume:false 是临时 `--config` overlay，不覆盖用户配置。
- 使用 native rpc-ui 适配原生事件；历史/设置使用原生已有格式和命令，不假装 RPC 拥有不存在的接口。
- 当前会话状态、全局设置、项目覆盖和环境覆盖须区分；共享配置变更会影响终端 omp。
- 历史查看、树浏览与原生执行分离：查看只读；明确续写保留原 ID，派生创建新 ID 且不改变来源。「会话历史与分支」区分从最新保存内容派生与仅原生支持时的从所选消息前派生，选择节点不自动执行分支写入。
- 终端持有时不能发送、抢占或删除。参与在场扩展的进程通过内核共享咨询锁和只读 socket 提供精确占用、状态及未落盘助手文字/思考；未参与进程才沿用标注的启发式，无法看到其未落盘文字。socket 超时为未知而非空闲；扩展不提供提示词、工具参数/输出或控制命令。
- 会话/工作区别名归一到真实路径，原生 header 与持久化仍是权威；只读历史可保留 clear/压缩前正文，但不等于原生当前模型上下文。fork 仍共享工作区。
- 输入区负责编辑/发送与计划、上下文、花费；实时状态位于回复位置的原位标题，仅标题离屏时由不改变布局的底部浮动行兜底，头部至多一个操作提示。终端持有使用紧凑只读栏与右侧派生，原生 ask 内联且保留可编辑草稿、禁发送并说明原因。派生只读取已保存来源，成功带上草稿/附件但不自动发送，没有独立 Continue 面板。
- 完整 JSONL/gzip 祖先历史、压缩/reset 记录及分批树节点只读呈现；保存子任务和资源按父来源授权，缺失/歧义/上限须可见，不能用原文替代完整聊天或把缺失子任务说成成功。

## 设置呈现

常用设置优先：可执行文件/工作目录、模型与服务商、思考级别、审批策略、必要运行状态。低频设置按类别默认折叠；不要求为每项设置制作专用表单。未展示的配置保留，不能被覆盖或重置。桌面偏好单独持久化；凭据不复制、不打印、不作为普通设置读取。

## 可观察验收

1. 实际 Electron 窗口呈现 PI 启发的固定中性深色布局与交互，侧栏、输入框和右面板可操作；不要求已移除的主题选择器。
2. 无 PI 内核依赖；实际启动本机 omp，能明确报告未安装/版本不支持/未配置模型等错误。
3. 新会话、只读历史/树、明确续写/fork、真实流式回复、工具事件、subagent 信息与停止行为完成各自闭环；打开历史不写源文件、不请求模型，命令受理不等于会话结束。
4. 用户请求/审批可回答；取消、进程退出与错误不会留下假运行状态或静默重试。
5. 附件与文件路径通过主进程受限访问，渲染器没有 Node 或任意命令执行能力；外链使用受限协议。
6. 设置读写作用于 omp，保留无关配置与秘密；高级项折叠，桌面偏好不污染 omp 的终端设置。
7. 会话搜索/文件与差异面板使用真实数据；未选项目/空目录有明确状态。无 Git 仓库仍可审阅本轮最终净结果；当前 Git 工作区视图单独说明无仓库，不作为本轮审阅前提。
8. 构建检查、实际 omp 场景、实际桌面视觉与交互分别记录证据；未执行的项目不标记通过。
9. 文档覆盖安装、启动、打包、配置所有权、限制与许可。
10. 终端空闲但仍存活时发送保持置灰；终端正常退出后重新观察为空闲，明确续写落盘到原 session ID，草稿与已加载旧历史保留。占用判断还须在主进程写入口执行，不能只靠禁用按钮。
11. 思考/工具过程紧凑且对象明确，用量区分本轮汇总、逐请求明细/子代理合计与全会话花费；未知费用隐藏，低于一美分显示 `<$0.01`，不伪造累计费用。
12. 大于 100,000 条目的主会话仍可按祖先链翻页；临时索引有资源上限和清理，不变成新的会话权威。归档 fork 保留原文件、明确暂存/完整性边界。
13. 保存子任务状态/失败、正文分页、图片与资源可访问；fork 接管后的保存子任务连续性须另验，不能由只读打开通过外推。
14. 原生设置/认证/审批与草稿/附件恢复分别验证；原生认证存在性不等于账号可用，商业 OAuth 与完整快捷键/平台矩阵不默认通过。
15. 逐字输入、用户归属 skill/collab 与代理分配可辨；隐藏指令仍隐藏，未知可见类型不默认变成助手答复。回执与原生历史分开，重复相同输入不靠正文合并，目标会话改变时拒绝误投。
16. 多片段答复、迟到/混合交付、未知所有权、错误部分正文及恢复状态分别可读；队列 ACK、单次 prompt_result 与完整 settled 不互相冒充。
17. 真实深层子任务与实时/保存切换保留祖先、分支和返回上下文；旧页/最新页、嵌套展开、焦点、选区、滚动及窄窗口阅读由编排者实际观察，合成来源与真实原生执行证据分开。
18. 本轮摘要与审阅使用同一最终净结果；重复修改不累计，已证明还原/创建后删除不列入。完整原始历史必须分段处理，累计页数、消息数、字节数、来源数、深度或操作数不作为终止理由；可选过程明细截断不影响最终归约。内容/哈希置信度独立，缺正文不能隐藏哈希确认变化，未知不当作零；活动/初始加载不提前显示最终卡，无法确定时保留已知文件与具体原因。来源展开与子证据保留授权，不能从同一区间变化推定作者。工作区扫描边界、真实证据缺口、单个 patch/diff 运算边界与 RAM 淘汰限制分别说明；重启后恢复必须单独实测。

## 并行协作规则

编排者拥有共享契约与集成。各执行者只修改分配目录；接口变化先通知编排者。执行中不运行构建、类型检查、测试或格式化；集成完成后统一验证并分派修复。禁止用空实现、模拟数据或禁用按钮冒充功能完成。
